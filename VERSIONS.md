# MarketMind Version Plan (V10-V29)

## V10 - Search & Filter Dashboard
- Search bar on dashboard to filter ideas by title/description
- Sort by date, viability score, name
- Grid/List view toggle

## V11 - Idea Templates
- Pre-built idea templates (Restaurant, SaaS, E-commerce, Consulting, etc.)
- One-click start from template with pre-filled fields
- Template gallery on /ideas/new

## V12 - Research History & Versioning
- Track when research was generated/regenerated
- Show "last researched" timestamp
- Allow re-researching individual sections (refresh data)

## V13 - AI Executive Summary
- Auto-generate a concise executive summary after all sections researched
- TL;DR card at top of idea detail
- Include in PDF export

## V14 - Collaboration & Sharing Improvements
- Shareable links with optional password protection
- View count on shared ideas
- Copy-to-clipboard for individual sections

## V15 - Notes & Annotations
- Add personal notes to any research section
- Highlight/bookmark important insights
- Notes persist in DB

## V16 - Market Trends Integration
- Trending industries/ideas section on dashboard
- AI-generated trend analysis
- "Hot" / "Rising" / "Saturated" market indicators

## V17 - Financial Projections
- Revenue projection calculator
- Break-even analysis
- Startup cost estimator with local pricing
- Charts for 1yr/3yr/5yr projections

## V18 - Competitor Deep Dive
- Dedicated competitor analysis page per idea
- Competitor cards with strengths/weaknesses
- Market positioning map (2x2 grid visualization)

## V19 - Action Plan Generator
- AI generates step-by-step action plan
- Timeline with milestones
- Checklist format with dependencies

## V20 - Mobile Polish & Gestures
- Swipe between research sections
- Pull-to-refresh on dashboard
- Bottom navigation bar on mobile
- Haptic feedback hints

## V21 - Dark/Light Theme Toggle
- System-aware theme detection
- Manual toggle in header
- Smooth theme transition animations

## V22 - Onboarding Tour
- First-time user guided tour
- Tooltips explaining each feature
- Skip option, remembers completion

## V23 - Idea Scoring Breakdown
- Detailed score breakdown (market size, competition, feasibility, etc.)
- Radar chart visualization
- Score comparison across ideas

## V24 - Export Improvements
- Export to Google Docs format
- Export to Notion-compatible markdown
- Improved PDF with charts rendered as images
- Email report to self

## V25 - AI Chat Assistant
- Chat interface to ask follow-up questions about your research
- Context-aware (knows your idea + research data)
- Floating chat bubble on idea detail page

## V26 - Idea Tags & Categories
- Custom tags for organizing ideas
- Category filters on dashboard
- Color-coded tag pills

## V27 - Weekly Digest & Insights
- Dashboard widget showing weekly research activity
- AI insights: "Based on your ideas, you're interested in X sector"
- Suggested related ideas

## V28 - Performance & Polish
- Image optimization, lazy loading
- Route prefetching
- Lighthouse audit fixes
- Loading state improvements

## V29 - Landing Page Redesign
- Animated hero with demo video/gif
- Social proof section (user count, ideas researched)
- Feature showcase with scroll animations
- CTA improvements, testimonial carousel
